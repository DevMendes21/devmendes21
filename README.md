## 🔭 What I'm building now

At Grupo Macro I technically lead the AI team, orchestrating voice agents, RPAs, carrier APIs (Vivo, TIM), messaging and CRMs in end-to-end flows. The code is private, but this is what it does:

- 🎙️ **Voice AI platform (0800):** fully automated sales and support calls with ElevenLabs Conversational AI, n8n orchestration, structured data extraction (with Gemini as fallback) and a Java 21 + Spring Boot 3 backend (Resilience4j, Redis, Prometheus).
- 🤖 **B2B telecom RPA:** distributed Python bots with queues, circuit breaker, rate limiting and automatic reprocessing.
- 🧾 **Speech-to-text extraction API:** turns call audio into structured sales data (name, document, address, plan) with timestamps.

**Production impact**
- ⚡ Up to **60%** latency reduction in critical flows
- 🟢 **99%** uptime in high-volume automations
- ⏱️ **85%** less manual work (B2B telecom RPA)

Previously at **Haaify**: chatbots, RAG-based conversation management (LangChain + FAISS) and WhatsApp automation for clients like Quartzo, RealVale and SportBras.
